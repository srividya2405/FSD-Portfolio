# Personal Portfolio - Full Stack Development Assignment 1

## Technologies
- HTML5 semantic elements
- CSS3, Flexbox, Grid and media queries
- Bootstrap 5
- JavaScript ES6+
- Browser Local Storage

## Features
1. Responsive mobile-first portfolio layout
2. Accessible navigation and form labels
3. Dark/light theme switching
4. Project filtering by category
5. Project details modal
6. Client-side contact form validation
7. Dynamic success/error messages
8. Education table and project cards

## Files
- `index.html` - portfolio structure
- `style.css` - custom styling and responsive design
- `script.js` - interactivity and validation

## Run
Open `index.html` in a browser. Internet access is required for the Bootstrap CDN.
